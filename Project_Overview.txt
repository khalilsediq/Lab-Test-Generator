# Lab Test Generator - Bug Fixes & Project Overview

## Active Bug Fixes Applied

### Bug 1: PDF Generation Crashes (OKLCH Color Parsing Error)
**Files Modified: `src/components/ReportPreview.jsx`, `src/index.css`**
*The version of html2canvas bundled inside html2pdf.js cannot parse modern Tailwind OKLCH variables natively.*
- **Layer 1 (Inline Resolver):** Mapped `window.getComputedStyle()` against all elements inside `ReportPreview.jsx` during PDF generation to force `color`, `backgroundColor` and `borderColor` into safe RGB equivalents.
- **Layer 2 (CSS Fallback):** Generated a specific `.pdf-capture-safe` class in `index.css` forcing Tailwind prose settings into absolute hex/rgb variables locally for the cloned layout.
- **Layer 3 (String Serialization Scrubber):** Bypassed the built-in React/DOM rendering engine bug by serializing the clone out as a raw HTML string `clone.outerHTML`, running a global regex substitution (`/oklch\([^)]+\)/g` -> `rgb(17, 24, 39)`), and rebuilding the element from scratch before appending it to the DOM for capturing.

### Bug 2: Download PDF Freezing
**Files Modified: `src/components/ReportPreview.jsx`**
*The UI locks entirely because the JS thread gets bottlenecked by the heavy rendering canvas map.*
- Wrapped the heavy `html2pdf().save()` call within `setTimeout(async () => {...}, 50)` yielding the JS Event Loop frame precisely long enough for React to render the "Generating..." spinner.
- Implemented visual disabling `disabled={isGeneratingPDF}` and CSS blockouts (opacity, cursor) for both the Download and Print buttons to prevent parallel threading conflicts.
- Appended a 30-second `Promise.race()` timeout guard to automatically reject and cleanup the `document.body` clone if the html2canvas renderer hangs internally.

### Bug 3: Scroll Bleeds Through to Background
**Files Modified: `src/components/ReportPreview.jsx`**
*When scrolling the modal preview list, the actual page underneath also receives the wheel event and drifts.*
- Bound `document.body.style.overflow = "hidden"` using a React `useEffect` firing strictly when the modal props flag `show` true. 
- Integrated native Tailwind containment (`overflow-hidden` on the overlay shield, `overflow-y-auto overscroll-contain` on the interior viewing block).
- Tied `e.stopPropagation()` strictly onto the inner preview container's `onWheel` and `onTouchMove` to prevent cascade DOM events.

### Bug 4: Patient Info Layout Discrepancy (Not Matching Client Design)
**Files Modified: `src/components/ReportTemplate.jsx`, `src/components/PatientForm.jsx`, `src/App.jsx`**
*The original grid layout did not match the client's reference design, which required a distinct barcode strip (Zone A) and a borderless detailed grid (Zone B) with specific fields.*
- **State Tracking:** Added `trId` (T/R ID) and `trNo` (T/R No) to the `patientDetails` state in `App.jsx` and created inputs for them in `PatientForm.jsx`.
- **Barcode Generation:** Installed `react-barcode` and implemented it in Zone A to dynamically render CODE128 visual barcodes for the Patient No and T/R ID fields.
- **Structural Overhaul:** Restructured the `ReportTemplate.jsx` patient info block into two explicit HTML zones. Zone A contains the top-bordered strip with three equidistant values. Zone B contains the borderless column layout exactly matching the requested labels (e.g., mapping "Father/Husband Name" to "S/O D/O W/O").
- **Typography Alignment:** Applied `font-normal`, `font-semibold`, and `font-bold` classes strategically to exactly match the bolded values and regular-weight labels from the reference image.

### Session 3: PDF Engine Overhaul + Page Layout Selector + Sticky Header/Footer (2026-03-03)

**Bug 5: Empty/Blank PDF Output (Complete Architecture Overhaul)**
**Files Changed: `src/utils/generatePDF.js` [NEW], `src/components/ReportPreview.jsx`, `src/components/ReportTemplate.jsx`, `src/index.css`**
*The `html2pdf.js` wrapper library has deeply embedded oklch color parsing bugs and treats off-screen clones inconsistently. Replaced the entire PDF pipeline.*

- **New Utility `src/utils/generatePDF.js`:** Standalone async function using `html2canvas` + `jsPDF` directly, bypassing the buggy `html2pdf.js` wrapper entirely. Key strategy:
  - Creates a `position:fixed; opacity:0; z-index:-9999` container so Tailwind styles resolve correctly without any visual side effect.
  - Runs two `requestAnimationFrame` frames after DOM insertion to guarantee browser layout/paint.
  - **Double-pass oklch resolver:** First strips oklch from all `<style>` tags in the document, then inlines all computed element colors as explicit `rgb()` strings. This is necessary because html2canvas reads CSS rules before `onclone` fires, so the fix must happen before html2canvas is called.
  - Multi-page slicing: canvas is sliced into page-height strips, each written to its own PDF page. Page numbers are stamped at the bottom right of each page.
  - Blob + `URL.createObjectURL` download strategy (reliable in both browser and Electron).

- **Feature 1 — Page Layout Selector:** Added compact toolbar in the Print Preview modal header with:
  - A4, A5, Letter, Legal, and Custom page size options.
  - Portrait / Landscape orientation toggle.
  - Custom size: two number inputs (Width mm × Height mm) appear when "Custom" is selected.
  - Preview aspect ratio updates live as the selection changes.
  - Print button dynamically injects a `<style id="dynamic-print-style">` tag with the correct `@page { size: ... }` rule before calling `window.print()`, then removes it.
  - PDF download passes the full layout object to `generatePDF()` which constructs `jsPDF` with the correct format/orientation.

- **Feature 2 — Sticky Header/Footer on Multi-Page Prints:** 
  - Added `report-header` CSS class to the lab branding div in `ReportTemplate.jsx`.
  - Added `report-footer` CSS class to the footer div.
  - Updated `index.css` with the CSS table trick (`display:table` on the print target, `display:table-header-group` for `.report-header`, `display:table-footer-group` for `.report-footer`), which causes browsers to natively repeat header and footer on every physical printed page.
